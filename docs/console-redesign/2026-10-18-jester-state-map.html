Run it today

two entry points

Operator console

http://localhost:8619
python -m jester.console --db data/jester.db --config config --port 8619

Serves the static operator UI (python/jester/console/static/) at / and the JSON API under /api/*. The UI ships its own woff2 fonts, so it works on machines with no internet.

Auth: GETs stay open so dashboards can poll. If JESTER_CONSOLE_TOKEN is set, every mutating POST needs Authorization: Bearer …. The console binds to localhost and serves only an allow-list of static file types.

The six daily commands

jester <cmd>
# fetch the curated sources with the Go worker
jester ingest
# ingest + run the whole pipeline over what was queued
jester cycle
# process the queue; stops when the LLM quota runs out
jester treat
# regroup the archive into semantic themes
jester cluster
# register the scrape+process cycle with the host scheduler
jester schedule
# check the pipeline isn't quietly under-delivering
jester doctor

Other chrome worth knowing

  • ●Hash routing — pages are section[data-page] toggled via hidden; the URL hash survives reloads.
  • ●Shared #drawer for detail views at every width, with return-focus restored on close.
  • ●Posts detail is an in-page view swap (#posts-list ↔ #post-detail) with a sticky back button.
  • ●A #runstrip poll every 15s shows the live run; clicking it goes to Runs.
  • ●Toast actions (requeue, re-embed) are offered right where Doctor/Overview report the failure.

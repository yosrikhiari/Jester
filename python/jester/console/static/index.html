    Infrastructure

    Quick actions

    run pipeline opens a dialog to pick the sources and an optional stop-at goal, then does the whole loop: fetch those sources with the Go worker, extract, archive and synthesize. ingest does the fetch half on its own, and the pipeline will still process anything already queued. Fetching needs the Go toolchain and cloakserve on :9222 — those buttons appear once both are reachable.

    Sources

    The curated ingest list the live worker walks — least recently fetched first, so a run with a depth ceiling spreads across the list instead of re-walking the top of it. Paste a subreddit, a thread, a YouTube channel or video, or a TikTok profile — anything the parser recognises.
